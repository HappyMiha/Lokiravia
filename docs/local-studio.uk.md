# Локальна AI-студія

[English](local-studio.en.md).

Lokiravia може передати збережену ідею локальному Core для планування без другого
ручного доручення. Це ще не автоматичне створення грабельної гри.

На тому самому ПК встановіть обидва проєкти з сумісною версією Core. Виконайте
`python -m agent_factory.studio_local_worker --workspace WORKSPACE --actor operator --run-live`
на ПК з Ollama й підтримуваною моделлю. Далі задайте у процесі Lokiravia:

```powershell
$env:LOKIRAVIA_CORE_WORKSPACE = 'C:\Work\local-studio'
$env:LOKIRAVIA_CORE_URL = 'http://127.0.0.1:8765'
```

Шлях задає оператор на сервері, а не браузер. База Core —
`WORKSPACE/.agent-factory/state.db`. URL повинен вести на loopback без облікових
даних. Ключі провайдерів не передаються через міст або URL.

У збереженій ідеї з'являється **Start local studio planning**. Кнопка використовує
автентифікованого власника та поточну збережену ревізію. Незбережені зміни потрібно
спочатку зберегти. Повтор запиту використовує той самий ключ ревізії й місію.
Посилання **Open studio progress** відкриває відповідну місію в Core.

Без налаштування міст вимкнений. Якщо модель не пройшла перевірку, запит не
створює місію. Сторонні власники, застаріла ревізія й підміна actor відхиляються.
Цей міст призначений для локального запуску; він не маршрутизує хмарні job-и до
ПК користувача. Детальний аудит відсутніх частин є в Core:
`docs/ai-studio-audit.uk.md`.
