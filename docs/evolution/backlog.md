# Lokiravia: пропозиція беклогу живого світу

Дата редакції: 2026-09-10. Q05 уточнює AF-LW023/030; IDs і залежності збережені. Статус: незалежна дослідницька пропозиція для консолідації з чинним беклогом, не затверджений план реалізації. 30 елементів `AF-LW-001`–`AF-LW-030`. Код не створюється.

Джерело натхнення: [дослідницька записка про три книги](running-safe-analysis.md). Конкретні сценарії нижче оригінальні; вони не відтворюють книжкові світи. Це ігровий шар: Cloud уже забезпечує авторські шляхи, а Core володіє загальними механізмами виконання, подій, еволюції, оцінювання та відкату. Тут описано, **що саме має бути можливим у світі та як це перевіряти**, а не повторну розробку auth, billing, import, build чи універсального evolution engine.

Зовнішні залежності сформульовано як потрібні контракти, не як твердження, що вони вже реалізовані. Числові пороги — початкові критерії приймання прототипу, які потребують перевірки. Дослідницькі інтерв’ю можуть змінити їх, але зміна має бути записана до повторного оцінювання.

**Межа першого Godot MVP: один гравець, співпраця й суспільні відносини з NPC.** У базових пунктах команда, громада, майстер і коаліція можуть повністю складатися з NPC. Людська кооперація — окреме необов’язкове дослідження AF-LW-029; жодна залежність початкового зрізу не вимагає її завершення. Зловживання багатьох акаунтів до появи multiplayer перевіряються як модель майбутнього ризику, а не як вимога створити мережевий режим. Наведені 30 пунктів охоплюють кілька горизонтів продукту й не означають, що всі 30 потрібні для першої Godot-демонстрації. **Перший вузький доказ — AF-LW-030; AF-LW-028 є пізнішим прийманням повного еволюційного кварталу.**

**Простежуваність:** «Підстави» відділяють натхнення від нашого дизайну; легенда — [source-guide.md](source-guide.md). «Контракти Core» є точними додатковими prerequisites поруч зі світовими залежностями. Обидва набори синхронізуються з JSON.

## AF-LW-001 — Конституція досвіду живого світу

**Результат:** спільне визначення того, що гравець може очікувати від мінливого світу: причинність, власність, доступний вихід, межі несподіванки, право на тиху гру.

**Приймання:** специфіковано щонайменше п’ять ситуацій: локальна дія без помітного наслідку; малий вчинок із великим наслідком; довгий план, який не спрацював; відмова від участі; повернення після зміни правил. Для кожної описані допустима невідомість, незмінні права й спосіб відновлення. Світові закони відділено від прав доступу та правил платформи.

**Неприйнятний випадок:** творча непередбачуваність виправдовує втрату приватного майна, доступу або керування без описаних меж.

**Залежності:** немає; звірка з чинною концепцією продукту.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** SAFE:L06, SAFE:L12, DESIGN:vision, REPO-AUDIT, USER:living-world

## AF-LW-002 — Ігрова модель подій і наслідків

**Результат:** світ знає, чому конкретний предмет, маршрут, NPC або суспільна послуга змінилися.

**Приймання:** для еталонного сценарію «перенесено громадський знак → змінився маршрут → затримався вантаж» кожен перехід має причину, час, версію правила, ініціатора або природне джерело, область впливу та відмінність від попереднього стану. Повторна доставка тієї самої події не дублює товар, винагороду або завдання. Художнє пояснення не створює окремого факту без переходу стану.

**Неприйнятний випадок:** NPC стверджує, що міст зруйновано, а маршрути, запаси й сусіди продовжують поводитися так, ніби він цілий.

**Залежності:** AF-LW-001. Зовні: Core event/state contract; новий універсальний журнал у Lokiravia не будується.

**Контракти Core:** core:AF-RSI-032

**Підстави:** SAFE:L10, SAFE:L11, TRANSFORMA:TR-S12, DESIGN:vision, REPO-AUDIT

## AF-LW-003 — Версійована книга законів і відкритих можливостей

**Результат:** гравці можуть досліджувати невідомі властивості, а автори розрізняють базове правило, локальний звичай, гіпотезу та помилкову чутку.

**Приймання:** для трьох матеріалів і двох місць описані відкриті властивості, ще не відомі гравцю властивості та заборонені переходи. Кожна активна механіка має версію й область дії. Непідтверджена гіпотеза не стає правилом тільки тому, що її впевнено переказав NPC. Незмінність права гравця не залежить від видимості книжки законів персонажу.

**Неприйнятний випадок:** після невдачі система вигадує нове правило заднім числом, щоб виправдати результат.

**Залежності:** AF-LW-001, AF-LW-002. Зовні: Core artifact/version registry.

**Контракти Core:** core:AF-RSI-002

**Підстави:** DESIGN:vision, REPO-AUDIT

## AF-LW-004 — Палітра композиційних можливостей для авторів

**Результат:** автор задає властивості й дозволені способи взаємодії, з яких гравці можуть складати непередбачені застосування.

**Приймання:** автор сцени описує щонайменше шість предметів через матеріал, форму, вагу, міцність, зв’язки й доступні дії. Два несподівані застосування проходять без додавання окремого квестового прапорця. Для кожного предмета є негативний приклад: що його властивості не дозволяють. Нова назва предмета не змінює властивостей. Думка, чутка, намір, пропозиція правила й авторизована дія мають різні типи; здогад гравця не стає законом лише через згадку.

**Неприйнятний випадок:** «будь-яке застосування» означає лише красивий текст, після якого світ не змінюється.

**Залежності:** AF-LW-001, AF-LW-003. Інтеграція в наявний авторський шлях Cloud, без дублювання редактора проєкту.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** SAFE:L02, SAFE:L04, TRANSFORMA:TR-S08, DESIGN:vision, REPO-AUDIT, TRANSFORMA:TR2-06

## AF-LW-005 — Розгляд незапланованої дії гравця

**Результат:** гравець може запропонувати новий спосіб дії та отримати виконуваний результат, уточнення або зрозумілу відмову.

**Приймання:** на п’яти заданих намірах система відділяє мету від способу; перевіряє матеріали, доступ і область впливу; виконує тільки дозволений перехід. Підтримані повний успіх, частковий успіх, діагностована невдача й потреба в уточненні. Формулювання «ігноруй правила світу» не дає додаткових прав. Якщо кілька способів рівноцінні, гравцеві залишено змістовний вибір. Для демонстраційного відкриття перелічені всі права, предмети, час, допомога й згоди; контроль без потрібного ресурсу не створює ефект, а новачок не отримує невидимого адміністративного бонусу.

**Неприйнятний випадок:** переконлива рольова аргументація дозволяє забрати чужий предмет або створити ресурс із нічого.

**Залежності:** AF-LW-002, AF-LW-004. Зовні: Core execution/permission contract.

**Контракти Core:** core:AF-RSI-031

**Підстави:** SAFE:L02, SAFE:L04, TRANSFORMA:TR-S08, DESIGN:vision, REPO-AUDIT, TRANSFORMA:TR2-05

## AF-LW-006 — Ремесло з матеріальною ціною та співучастю

**Результат:** спільне виготовлення речі є корисною пригодою, де зберігаються матеріали, авторство й різні види цінності.

**Приймання:** для одного виробу працюють три складання з різними компромісами; матеріали списуються один раз; невикористані рештки повертаються; внесок двох майстрів зберігається. Одне складання найкраще для переносимості, інше — для довговічності, третє — для конкретного простору. Жодне не найкраще за всіма критеріями. Повтор стандартного рецепта не отримує безмежну винагороду за «новизну».

**Неприйнятний випадок:** остання дія привласнює все авторство або повторне складання друкує матеріали.

**Залежності:** AF-LW-005.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** SAFE:L01, SAFE:L02, SAFE:L04, DESIGN:vision, REPO-AUDIT

## AF-LW-007 — Продуктивна помилка і вторинне застосування

**Результат:** частина невдалих виробів дає нову інформацію чи іншу можливість, не перетворюючи навмисне псування на лотерею.

**Приймання:** автор задає три можливі дефекти, їхнє походження, спостережувані ознаки, ремонт і вторинне використання. Один предмет можна зберегти дефектним, інший — вигідніше розібрати. Повтор тих самих умов відтворює ефект. Двадцять однакових навмисних помилок не дають гарантованого позитивного прибутку або зростання шансу рідкісного дропа.

**Неприйнятний випадок:** слово «експеримент» дає безмежно сильні випадкові властивості або приховує невідворотний штраф.

**Залежності:** AF-LW-006.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** SAFE:L03, DESIGN:vision, REPO-AUDIT

## AF-LW-008 — Область впливу та зрозумілий ризик пригоди

**Результат:** гравець може обрати ризик, а сторонні люди не стають безправним матеріалом для видовища.

**Приймання:** кожна експериментальна дія класифікує вплив на себе, групу, громадський простір і чуже майно. Для переходу межі потрібні відповідні права або заздалегідь прийняті правила місця. Є малий пробний режим, вихід і відновлення. Запрошення на локальну пригоду не дає згоди на довічну зміну персонажа. Втрата керування завжди обмежена й не блокує вихід із гри. Життєвий цикл зобов’язання: виявлена можливість → запропоновано → явно прийнято → виконано/припинено. Строк, відома ціна й клас можливої втрати доступні до прийняття; ввічлива репліка, огляд і вихід із сесії не приймають витратного контракту.

**Неприйнятний випадок:** новий гравець отримує багатогодинне покарання за чужу кумедну дію, про ризик якої не міг дізнатися.

**Залежності:** AF-LW-001, AF-LW-002, AF-LW-005.

**Контракти Core:** core:AF-RSI-031

**Підстави:** SAFE:L11, SAFE:L12, TRANSFORMA:TR-S04, DESIGN:vision, REPO-AUDIT, TRANSFORMA:TR2-02

## AF-LW-009 — Перспективна пам’ять NPC і свідків

**Результат:** мешканці знають лише те, що могли побачити, почути або вивчити; одна подія має кілька осмислених перспектив.

**Приймання:** у сценарії з трьома NPC один бачить дію, другий — наслідок, третій нічого не знає. Їхні відповіді різні й простежуються до джерела. Переказ може бути неповним, але не підмінює факт у моделі світу. Виправлення відомості не стирає саму подію, а змінює знання про неї. Приватні дії не доступні всім мешканцям за замовчуванням.

**Неприйнятний випадок:** світова енциклопедія випадково стає всезнанням кожного персонажа.

**Залежності:** AF-LW-002, AF-LW-003. Зовні: Core provenance/memory contract.

**Контракти Core:** core:AF-RSI-031, core:AF-RSI-032

**Підстави:** SAFE:L11, DESIGN:vision, REPO-AUDIT

## AF-LW-010 — Сліди, за якими гравець може відновити причинність

**Результат:** незрозумілий наслідок стає досліджуваною історією, а не відчуттям сваволі генератора.

**Приймання:** для одного віддаленого наслідку існують щонайменше два незалежні шляхи пояснення: матеріальний слід і свідок. Гравець може відтворити три ключові переходи без доступу до службового журналу. Непізнане майбутнє не розкривається через пояснення минулого. Після спростування чутки інтерфейс відділяє перевірені факти від того, у чому персонаж помилявся.

**Неприйнятний випадок:** пояснення додає нові факти, яких не було, або видає майбутній сюжет під виглядом прозорості.

**Залежності:** AF-LW-009.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** SAFE:L11, DESIGN:vision, REPO-AUDIT

## AF-LW-011 — Каскади з порогами, затримкою та згасанням

**Результат:** деякі малі дії поширюються далеко, більшість залишаються малими; обидва результати є нормальними.

**Приймання:** один сценарій має три варіанти стану: каскад згасає, обмежується районом або переходить до сусідньої системи через явну залежність. Є бюджет розгалужень, час поширення, умови зупинки та граничний радіус. Перезапуск обробки не подвоює події. Відсутність цікавого наслідку не запускає автоматичну компенсацію новою драмою.

**Неприйнятний випадок:** кожна дія мусить закінчитися катастрофою або один взаємний тригер породжує нескінченний потік подій.

**Залежності:** AF-LW-002, AF-LW-005, AF-LW-008, AF-LW-009. Зовні: Core scheduling/budget contract.

**Контракти Core:** core:AF-RSI-033

**Підстави:** SAFE:L10, SAFE:L11, TRANSFORMA:TR-S12, DESIGN:vision, REPO-AUDIT, USER:living-world

## AF-LW-012 — Контрфактичний перегляд світового сценарію

**Результат:** автор і дослідник можуть перевірити «що було б, якби» на копії стану, не змінюючи живу гру.

**Приймання:** одна зафіксована сцена відтворюється за тією самою версією правил, початковим станом і керованою випадковістю. Зміна одного рішення утворює окрему гілку з порівнянням наслідків, витрат і потерпілих. Копія не створює нагород, повідомлень чи соціальних записів у живому світі. Якщо для певного генератора точне відтворення неможливе, межа відтворюваності позначена й використовується набір повторів.

**Неприйнятний випадок:** replay потай виконує реальну покупку, змінює репутацію або показує вигадану точність.

**Залежності:** AF-LW-002, AF-LW-003, AF-LW-011. Зовні: Core sandbox/replay contract.

**Контракти Core:** core:AF-RSI-009, core:AF-RSI-032

**Підстави:** DESIGN:vision, REPO-AUDIT, CONTRACT:platform-world, RSI-SURVEY:R04

## AF-LW-013 — Авторська лабораторія однієї сцени

**Результат:** у наявному авторському шляху Cloud можна перевірити простір можливостей сцени до її публікації.

**Приймання:** автор задає потреби NPC, предмети, дозволені перетворення, область ризику, два очікувані шляхи й один заборонений перехід. Лабораторія програє варіанти та показує різницю між задумом і фактичним результатом. Автор може переглянути причинні сліди й обґрунтувати зміну. Власний тестовий приклад не вважається незалежним доказом якості.

**Неприйнятний випадок:** красиве прев’ю приховує неможливий перехід стану або публікує сцену без перевірки меж.

**Залежності:** AF-LW-004, AF-LW-005, AF-LW-007, AF-LW-012. Зовні: наявний Cloud creator workflow.

**Контракти Core:** немає прямих нових контрактів; транзитивні залежать від інших карток

**Підстави:** DESIGN:vision, REPO-AUDIT

## AF-LW-014 — Режисура гумору як налаштування досвіду

**Результат:** світ має впізнаваний комедійний тон, який не примушує кожну сцену жартувати.

**Приймання:** для однієї ситуації підготовлені стриманий, теплий і карнавальний варіанти; факти й наслідки не змінюються через тон. Є ліміт повтору жарту й пауза після емоційної сцени. Користувач може зменшити інтенсивність без ігрового штрафу. Реальні платежі, права, підтримка й попередження про ризик залишаються ясними. Novelty, completion і ресурсна винагорода розділені; grant посилається на чинний rule digest і виконану умову. Повтор не винагороджується через приховане переписування критерію; система не спрямовує небажаний розвиток під виглядом випадковості.

## AF-LW-030 — Перший однокористувацький доказ за 30 хвилин

**Результат:** один гравець у невеликій Godot-сцені перевіряє головну обіцянку: незвичну дію можна виконати; її наслідок може поширитися або згаснути; продуманий план може не спрацювати; збереження утримує чесну історію.

**Приймання:** готовий сценарій на 20–30 хвилин із двома NPC та кількома предметами. Гравець використовує побутовий предмет незапланованим способом. За одного набору місцевих умов виникає короткий причинний ланцюг із двох-трьох переходів; контрфактичний варіант зупиняє його без штучної компенсаційної драми. Попередньо підготовлений багатокроковий задум може провалитися з видимою причиною та доступним наступним вибором. Save/load через кваліфікований Play/checkpoint adapter зберігає витрачені предмети, знання NPC, прийняті domain jobs/scheduled events із stable IDs та версію правил без дублювання нагород. Незавершені model/action proposals старої сесії інвалідуються: save під час pending reply → load у новий session epoch → стару відповідь відхилено → новий request не дублює вже прийнятий ефект. Один спостерігач фіксує, чи тестувальник зрозумів причину, побачив вибір і пережив хоча б один доречний комічний момент. Висновок є якісним свідченням однієї сесії, а не статистичним доказом продуктового успіху. Окремий RC15 interleaving: reply пройшов precheck → save/load → old apply відхилено на commit. State/resource/event/job completion/dedup мають узгоджену локальну межу; звичайний restart не створює нової історії заради повторної нагороди.

**Межа:** немає вимоги повної економіки, установ, громадського голосування, довготривалих традицій, canary-публікації чи автономного самовдосконалення світу. Можна використовувати вручну задану сцену й фіксовані властивості, чесно позначивши їх. Важливий реальний перехід стану, а не універсальність генератора. Тиха пауза можлива без системи подарунків і пам’ятних предметів AF-LW-016. Людська кооперація не потрібна.

**Неприйнятний випадок:** дивина існує тільки в репліці; наслідок завжди однаково глобальний; невдача плану нічим не обґрунтована; save/load переписує минуле; або демо чекає готовності всіх пізніх AF-LW-018–029. Job позначено completed без effect або ресурс видано без event/dedup; стара відповідь застосовується після load через раніше успішний precheck.

**Залежності:** AF-LW-001, AF-LW-002, AF-LW-003, AF-LW-004, AF-LW-005, AF-LW-008, AF-LW-009, AF-LW-011, AF-LW-012, AF-LW-014. Зовні: чинні Godot Play/save/load paths.

AF-LW-010 входить транзитивно через AF-LW-014. AF-LW-006–007, AF-LW-013, AF-LW-015–029 не потрібні для цього критерію.

**Контракти Core:** core:AF-RSI-031, core:AF-RSI-032, core:AF-RSI-033

**Підстави:** SAFE:L02, SAFE:L11, TRANSFORMA:TR-S08, TRANSFORMA:TR-S12, TRANSFORMA:TR-S13, DESIGN:vision, REPO-AUDIT, USER:living-world, CONTRACT:recovery
